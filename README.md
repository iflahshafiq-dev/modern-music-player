# modern-music-player
A modern responsive music player built with HTML, CSS and JavaScript featuring playlist management, playback controls and a clean dark UI.

## Features

- Play & Pause
- Next / Previous
- Playlist
- Progress Bar
- Volume Control
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript
